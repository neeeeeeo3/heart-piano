# ハートピアノ

PCのキーボードを使って、ブラウザ上で3オクターブ分の音を演奏できるミニピアノです。

キーを押すと音が鳴り、画面上の操作キーとピアノ鍵盤がピンク色に光ります。同時にハートが少しだけ大きくなり、左右へランダムに傾きます。

## 主な機能

- PCキーボードによる3オクターブ分の演奏
- 複数キーを使った和音の演奏
- 押したキーと対応するピアノ鍵盤の点灯
- 演奏に合わせたハートのアニメーション
- コンプレッサーによる音割れの軽減
- 入力されたキーコードのデバッグ表示

## ファイル構成

```text
heart-piano/
├── index.html   ページの内容と基本構造
├── style.css    色、サイズ、配置などの見た目
├── script.js    鍵盤の生成、キー入力、音の再生
└── README.md    この説明書
```

4つのファイルは、すべて同じフォルダに置いてください。ファイル名を変更すると、`index.html`からCSSやJavaScriptを読み込めなくなる場合があります。

## 動作環境

次のような、Web Audio APIに対応した新しいバージョンのブラウザで動作します。

- Google Chrome
- Microsoft Edge
- Firefox
- Safari

Google Fontsを読み込むため、最初の表示時にはインターネット接続が必要です。フォントを除くピアノの基本機能は、外部ライブラリを使用していません。

## 起動方法

1. `index.html`、`style.css`、`script.js`を同じフォルダに入れます。
2. `index.html`をダブルクリックします。
3. ブラウザにハートピアノが表示されたら、対応するキーを押します。

インストールやビルド作業は必要ありません。通常のキーボードで演奏する場合、AutoHotkeyも不要です。

## キー配置

音域は、MIDIノート番号36〜72のC2からC5までです。

### 高音域：C4〜C5

画面上では、白鍵が`Q W E R T Y U I`、黒鍵が`2 3 5 6 7`の並びです。

| キー | 音名 | MIDI番号 |
| --- | --- | ---: |
| `Q` | ド（C4） | 60 |
| `2` | ド#（C#4） | 61 |
| `W` | レ（D4） | 62 |
| `3` | レ#（D#4） | 63 |
| `E` | ミ（E4） | 64 |
| `R` | ファ（F4） | 65 |
| `5` | ファ#（F#4） | 66 |
| `T` | ソ（G4） | 67 |
| `6` | ソ#（G#4） | 68 |
| `Y` | ラ（A4） | 69 |
| `7` | ラ#（A#4） | 70 |
| `U` | シ（B4） | 71 |
| `I` | ド（C5） | 72 |

### 中音域：C3〜B3

画面上では、白鍵が`Z X C V B N M`、黒鍵が`S D G H J`の並びです。

| キー | 音名 | MIDI番号 |
| --- | --- | ---: |
| `Z` | ド（C3） | 48 |
| `S` | ド#（C#3） | 49 |
| `X` | レ（D3） | 50 |
| `D` | レ#（D#3） | 51 |
| `C` | ミ（E3） | 52 |
| `V` | ファ（F3） | 53 |

| `J` | ラ#（A#3） | 58 |

### 低音域：C2〜B2

画面上では、白鍵が`, . / O P [ ]`、黒鍵が`L ; 0 - ^`の並びです。

| キー | 音名 | MIDI番号 |
| --- | --- | ---: |

## 各ファイルの役割

### index.html

ページに何を表示するかを決めるファイルです。

- タイトル
- ハート
- 操作用鍵盤の配置先
- ピアノビジュアライザーの配置先
- システム状態とデバッグ情報

鍵盤そのものはHTMLへ直接書かず、`script.js`が自動で追加しています。

### style.css

ページの見た目を決めるファイルです。

- 背景のグラデーション
- 文字や鍵盤の色
- 各要素の幅、高さ、余白
- 押しているキーの発光表現
- ハートの影と動きの速さ

ピンク系の基本色には、主に`#ff0077`を使用しています。

### script.js

ピアノの動作を担当するファイルです。

処理は次の順番で構成されています。

1. 音を出すための準備
2. キーボードと音程の対応付け
3. 画面上の鍵盤作成
4. 音を鳴らす処理
5. キーを押したとき・離したときの処理

## 処理の流れ

キーを押したときは、次の順番で処理されます。

1. ブラウザが物理キーの位置を`event.code`として取得します。
2. `codeToKey`が、その位置を`q`や`2`などの文字へ変換します。
3. `keyMap`が、文字をMIDIノート番号へ変換します。
4. `play()`がMIDIノート番号から周波数を計算して音を作ります。
5. 対応する操作キーとピアノ鍵盤へ`active`クラスを追加します。
6. CSSが`active`クラスの付いた鍵盤をピンク色にします。

キーを離すと`active`クラスが削除され、鍵盤の色が元に戻ります。

## カスタマイズ方法

### ページタイトルを変更する

`index.html`にある次の2か所を変更します。

```html
<title>ハートピアノ - Multi-File Edition</title>
<h2>✨ ハートピアノ ✨</h2>
```

`title`はブラウザのタブ、`h2`はページ内に表示される名前です。

### 基本色を変更する

`style.css`内で使用されている`#ff0077`を、好きな色コードへ変更します。

例として、水色にする場合は`#00bfff`などを使用できます。すべてを一括置換する前に、元ファイルのコピーを保存しておくと安全です。

### 全体の音量を変更する

`script.js`の次の値を変更します。

```javascript
masterGain.gain.value = 0.25;
```

`0`が無音、`1`が最大値の目安です。急に大きな値へ変更せず、少しずつ調整してください。

### 音色を変更する

`play()`内の`harmonics`を変更します。

```javascript
const harmonics = [
  { ratio: 1, type: 'triangle', volume: 0.4, duration: 1.2 },
  { ratio: 2, type: 'sine', volume: 0.1, duration: 0.8 },
  { ratio: 0.5, type: 'sine', volume: 0.2, duration: 1.5 }
];
```

各項目の意味は次のとおりです。

| 項目 | 意味 |
| --- | --- |
| `ratio` | 基本音に対する周波数の倍率 |
| `type` | 波形の種類。`sine`、`triangle`、`square`、`sawtooth`など |
| `volume` | その音の音量 |
| `duration` | 音が消えるまでのおおよその秒数 |

### キーと音程の組み合わせを変更する

`script.js`の`keyMap`で、キーに対応するMIDIノート番号を変更します。

```javascript
const keyMap = {
  'q': 60,
  'w': 62,
  'e': 64
};
```

MIDIノート番号では、60が中央のドであるC4、69がA4です。このピアノではA4を440Hzとして周波数を計算しています。

画面に表示する並びも変更する場合は、`boardLayout`も同時に編集してください。

## よくあるトラブル

### キーを押しても音が鳴らない

- 先にページ内を一度クリックしてからキーを押してください。
- ブラウザやPCがミュートになっていないか確認してください。
- `script.js`が`index.html`と同じフォルダにあるか確認してください。
- 開発者ツールのConsoleに赤いエラーが出ていないか確認してください。

ブラウザは、ユーザー操作前の音声再生を制限することがあります。このサイトではキー入力時にAudioContextの再開を試みています。

### デザインが反映されない

- ファイル名が正確に`style.css`になっているか確認してください。
- `style.css`が`index.html`と同じフォルダにあるか確認してください。
- ブラウザを再読み込みしてください。古いCSSが残る場合は、強制再読み込みを試してください。

### 一部のキーだけ反応しない

画面下部のデバッグ表示を確認してください。認識された物理キーのコードと、変換後のキーが表示されます。

特に`^`キーは、キーボード配列やOSによって`Equal`または`IntlRo`など異なるコードになる場合があります。必要に応じて、`script.js`の`codeToKey`へ自分の環境で表示されたコードを追加してください。

### フォントが見本と異なる

Google Fontsを読み込めていない可能性があります。インターネット接続を確認してください。読み込めない場合は、代替フォントの`sans-serif`で表示されます。
