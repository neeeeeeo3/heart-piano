# ハートピアノ

PCのキーボードを使って、ブラウザ上で3オクターブ分の音を演奏できるミニピアノです。

キーを押すと音が鳴り、画面上の操作キーとピアノ鍵盤がピンク色に光ります。同時にハートが少しだけ大きくなり、左右へランダムに傾きます。

リポジトリには、通常のキーボード演奏に加えて、CSVの音符データを読み込み、AutoHotkey v2からハートピアノへキー入力を送る自動演奏ツールも同梱しています。ハートピアノ単体でも利用でき、自動演奏ツールの導入は任意です。

## 主な機能

- PCキーボードによる3オクターブ分の演奏
- 複数キーを使った和音の演奏
- 押したキーと対応するピアノ鍵盤の点灯
- 演奏に合わせたハートのアニメーション
- コンプレッサーによる音割れの軽減
- 入力されたキーコードのデバッグ表示
- GitHub Pagesを使った静的サイトとしての公開
- AutoHotkey v2とCSVを使った自動演奏（Windows向け・任意）

## 動作環境

次のような、Web Audio APIに対応した新しいバージョンのブラウザで動作します。

- Google Chrome
- Microsoft Edge
- Firefox
- Safari

Google Fontsを読み込むため、最初の表示時にはインターネット接続が必要です。フォントを除くピアノの基本機能は、外部ライブラリを使用していません。

自動演奏ツールを使用する場合のみ、WindowsとAutoHotkey v2.0が必要です。macOS、Linux、スマートフォンではハートピアノを表示できますが、同梱の`.ahk`ファイルは実行できません。

## ハートピアノの起動方法

### GitHub Pagesから起動する

GitHub Pagesを有効にしている場合は、公開されたサイトURLへアクセスします。一般的なURL形式は次のとおりです。

```text
https://GitHubユーザー名.github.io/リポジトリ名/
```

GitHub Pagesの公開元は、`main`ブランチの`/(root)`に設定してください。リポジトリ直下の`index.html`がサイトの入口として読み込まれます。

### PC上で起動する

1. `index.html`、`style.css`、`script.js`を同じフォルダに入れます。
2. `index.html`をダブルクリックします。
3. ブラウザにハートピアノが表示されたら、対応するキーを押します。

インストールやビルド作業は必要ありません。通常のキーボードで演奏する場合、AutoHotkeyも不要です。

## 自動演奏ツールの使い方

自動演奏ツールは、CSVに記録された音符と時刻を解析し、ハートピアノへ物理キーボード入力として送信します。WindowsとAutoHotkey v2.0が必要です。

1. AutoHotkey v2.0をWindowsへインストールします。
2. ハートピアノをGitHub Pagesまたはローカルの`index.html`で開きます。
3. `自動演奏ツール/自動演奏ツール.ahk`を起動します。
4. ファイル選択画面から、同梱されたCSVまたは対応形式のCSVを選択します。
5. ツールに`READY: F1 TO START`と表示されるまで待ちます。
6. ハートピアノを開いているブラウザをクリックし、操作対象にします。
7. `F1`を押して自動演奏を開始します。
8. 途中で停止する場合は`Esc`を押します。

自動演奏ツールは、その時点で操作対象になっているウィンドウへキー入力を送信します。ブラウザ以外の画面を選択したまま`F1`を押さないでください。

同梱されている演奏データは次の3曲です。

| CSVファイル | 収録曲 |
| --- | --- |
| `乙女の祈り.csv` | 乙女の祈り |
| `幻想即興曲.csv` | 幻想即興曲 |
| `月の光.csv` | 月の光 |

現在のキーマップでは、自動演奏ツール内部で処理しているMIDIノートより、ハートピアノから鳴る音が1オクターブ低くなります。CSV形式、演奏スタイル、安全上の注意、詳細な制限については、[自動演奏ツールのREADME](../自動演奏ツール/自動演奏ツール-README.md)を参照してください。

## キー配置

音域は、MIDIノート番号36〜72のC2からC5までです。

### 高音域：C4〜C5

画面上では、白鍵が`Q W E R T Y U I`、黒鍵が`2 3 5 6 7`の並びです。

| キー | 音名 | MIDI番号 |
| --- | --- | ---: |
| `Q` | ド（C4） | 60 |
| `2` | ド#（C#4） | 61 |
| `W` | レ（D4） | 62 |
| `3` | レ#（D#4） | 63 |
| `E` | ミ（E4） | 64 |
| `R` | ファ（F4） | 65 |
| `5` | ファ#（F#4） | 66 |
| `T` | ソ（G4） | 67 |
| `6` | ソ#（G#4） | 68 |
| `Y` | ラ（A4） | 69 |
| `7` | ラ#（A#4） | 70 |
| `U` | シ（B4） | 71 |
| `I` | ド（C5） | 72 |

### 中音域：C3〜B3

画面上では、白鍵が`Z X C V B N M`、黒鍵が`S D G H J`の並びです。

| キー | 音名 | MIDI番号 |
| --- | --- | ---: |
| `Z` | ド（C3） | 48 |
| `S` | ド#（C#3） | 49 |
| `X` | レ（D3） | 50 |
| `D` | レ#（D#3） | 51 |
| `C` | ミ（E3） | 52 |
| `V` | ファ（F3） | 53 |
| `G` | ファ#（F#3） | 54 |
| `B` | ソ（G3） | 55 |
| `H` | ソ#（G#3） | 56 |
| `N` | ラ（A3） | 57 |
| `J` | ラ#（A#3） | 58 |
| `M` | シ（B3） | 59 |

### 低音域：C2〜B2

画面上では、白鍵が`, . / O P [ ]`、黒鍵が`L ; 0 - ^`の並びです。

| キー | 音名 | MIDI番号 |
| --- | --- | ---: |
| `,` | ド（C2） | 36 |
| `L` | ド#（C#2） | 37 |
| `.` | レ（D2） | 38 |
| `;` | レ#（D#2） | 39 |
| `/` | ミ（E2） | 40 |
| `O` | ファ（F2） | 41 |
| `0` | ファ#（F#2） | 42 |

| `-` | ソ#（G#2） | 44 |
| `[` | ラ（A2） | 45 |
| `^` | ラ#（A#2） | 46 |
| `]` | シ（B2） | 47 |

## 処理の流れ

キーを押したときは、次の順番で処理されます。

1. ブラウザが物理キーの位置を`event.code`として取得します。
2. `codeToKey`が、その位置を`q`や`2`などの文字へ変換します。
3. `keyMap`が、文字をMIDIノート番号へ変換します。
4. `play()`がMIDIノート番号から周波数を計算して音を作ります。
5. 対応する操作キーとピアノ鍵盤へ`active`クラスを追加します。
6. CSSが`active`クラスの付いた鍵盤をピンク色にします。

キーを離すと`active`クラスが削除され、鍵盤の色が元に戻ります。

## カスタマイズ方法

### ページタイトルを変更する

`index.html`にある次の2か所を変更します。

```html
<title>ハートピアノ - Multi-File Edition</title>
<h2>✨ ハートピアノ ✨</h2>
```

`title`はブラウザのタブ、`h2`はページ内に表示される名前です。

### 基本色を変更する

`style.css`内で使用されている`#ff0077`を、好きな色コードへ変更します。

例として、水色にする場合は`#00bfff`などを使用できます。すべてを一括置換する前に、元ファイルのコピーを保存しておくと安全です。

### 全体の音量を変更する

`script.js`の次の値を変更します。

```javascript
masterGain.gain.value = 0.25;
```

`0`が無音、`1`が最大値の目安です。急に大きな値へ変更せず、少しずつ調整してください。

### 音色を変更する

`play()`内の`harmonics`を変更します。

```javascript
const harmonics = [
  { ratio: 1, type: 'triangle', volume: 0.4, duration: 1.2 },
  { ratio: 2, type: 'sine', volume: 0.1, duration: 0.8 },
  { ratio: 0.5, type: 'sine', volume: 0.2, duration: 1.5 }
];
```

各項目の意味は次のとおりです。

| 項目 | 意味 |
| --- | --- |
| `ratio` | 基本音に対する周波数の倍率 |
| `type` | 波形の種類。`sine`、`triangle`、`square`、`sawtooth`など |
| `volume` | その音の音量 |
| `duration` | 音が消えるまでのおおよその秒数 |

### キーと音程の組み合わせを変更する

`script.js`の`keyMap`で、キーに対応するMIDIノート番号を変更します。

```javascript
const keyMap = {
  'q': 60,
  'w': 62,
  'e': 64
};
```

MIDIノート番号では、60が中央のドであるC4、69がA4です。このピアノではA4を440Hzとして周波数を計算しています。

画面に表示する並びも変更する場合は、`boardLayout`も同時に編集してください。

## よくあるトラブル

### キーを押しても音が鳴らない

- 先にページ内を一度クリックしてからキーを押してください。
- ブラウザやPCがミュートになっていないか確認してください。
- `script.js`が`index.html`と同じフォルダにあるか確認してください。
- 開発者ツールのConsoleに赤いエラーが出ていないか確認してください。

ブラウザは、ユーザー操作前の音声再生を制限することがあります。このサイトではキー入力時にAudioContextの再開を試みています。

### デザインが反映されない

- ファイル名が正確に`style.css`になっているか確認してください。
- `style.css`が`index.html`と同じフォルダにあるか確認してください。
- ブラウザを再読み込みしてください。古いCSSが残る場合は、強制再読み込みを試してください。

### 一部のキーだけ反応しない

画面下部のデバッグ表示を確認してください。認識された物理キーのコードと、変換後のキーが表示されます。

特に`^`キーは、キーボード配列やOSによって`Equal`または`IntlRo`など異なるコードになる場合があります。必要に応じて、`script.js`の`codeToKey`へ自分の環境で表示されたコードを追加してください。

### フォントが見本と異なる

Google Fontsを読み込めていない可能性があります。インターネット接続を確認してください。読み込めない場合は、代替フォントの`sans-serif`で表示されます。

### GitHub PagesでREADMEが表示される

リポジトリ直下に`index.html`がない場合、GitHub PagesがREADMEをサイトの入口として表示することがあります。

次の3ファイルが、`README.md`と同じ一番上の階層にあるか確認してください。

```text
index.html
style.css
script.js
```

Pagesの公開元も、`main`ブランチの`/(root)`になっていることを確認してください。

### 自動演奏ツールを起動できない

- WindowsへAutoHotkey v2.0がインストールされているか確認してください。
- `.ahk`ファイルがAutoHotkey v1へ関連付けられていないか確認してください。
- ファイル名の拡張子が`.ahk`になっているか確認してください。

### F1を押しても自動演奏されない

- ツールに`READY: F1 TO START`と表示されているか確認してください。
- 先にハートピアノを開いているブラウザをクリックしてください。
- CSVが自動演奏ツールの対応形式になっているか確認してください。
- 対象ブラウザとAutoHotkeyの実行権限が大きく異なっていないか確認してください。

### 自動演奏のキーが別の画面へ入力される

自動演奏ツールは、`F1`を押した時点で選択されているウィンドウへキー入力を送信します。演奏開始前に、必ずハートピアノを表示しているブラウザをクリックしてください。
